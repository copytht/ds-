# 页面动作候补清单（#15 最小单元之外）

来源 GitHub issue #30。这里登记 DeepSeek 页面上**不在** `#15` 15 个最小单元里的控件，
按同一套写法给动作名 / 定位 / 返回形状；**v1 只实现两个开关**，其余只登记、不实现。

> **登记 ≠ 名册**：只登记的动作**不写进** `entrypoints/content.ts` 的 `ACTION_ROSTER`——
> 写了却没执行器，点下去只会回 `unknown-action`，是假实现。
> 已实现动作另见 `protocol/fixtures/action.json` 与 `src/lib/page.ts`。

定位口径（#15）：优先站点设计系统的 `ds-*` / `role` / `aria-*` 与语义属性，
**不碰**随部署变的哈希 class。

## v1（已实现）

| 控件          | 动作名                      | 定位                                                         | 返回形状               | 备注                                          |
| ------------- | --------------------------- | ------------------------------------------------------------ | ---------------------- | --------------------------------------------- |
| 深度思考 开关 | `think.get` / `think.set`   | `div.ds-toggle-button`，文字 `深度思考`；状态 `aria-pressed` | `{ enabled: boolean }` | 文字本地化，只认中文；找不到回 `page-changed` |
| 智能搜索 开关 | `search.get` / `search.set` | `div.ds-toggle-button`，文字 `智能搜索`；状态 `aria-pressed` | `{ enabled: boolean }` | 同上；`set` 幂等，回达成态                    |

`set` 的 `params` 是 `{ enabled: boolean }`；两个 `set` 是写动作，记在
`BACKOFF_GATED_ACTIONS`（禁言中回 `backing-off`），**不**进「代你发言」闸。
