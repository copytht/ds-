# Spec: watchdog

## Purpose

链子看门狗：网页漂走了拉回来，静默了就催一轮，连催停手（ADR-0006 / #24）。

## Requirements

### 漂移拉回
页面写作框或结构变化时，`page.state` 重新探测，若认不出则回 `page-changed` 而非盲目写动作。

### 静默催办
一轮问句静默（无事件流、无消息变化）满一个窗口（`DSB_IDLE_TIMEOUT` 默认 600s）才判超时，在动就一直等；另有硬顶兜底防打转。

### 连催停手
同一故障只记一笔（开始时刻）；重复探活 / 轮询失败视为同一段红着的延续，不重复记日志刷配额。
